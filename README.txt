PAW SCHOOL 2.0 — iPhone and desktop

Start with index.html on a computer. For iPhone installation, host all five app files in the same folder on an HTTPS static host (e.g., GitHub Pages). On GitHub: create a repository, upload index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png to the root, then Settings > Pages > Deploy from a branch > main > / (root) > Save. Open the published URL in Safari on the iPhone. Tap Share > Add to Home Screen > Add. The app is private by design in that records remain on the device, but the hosted app files are public if using a public repository. Do not put personal information in the repository. Offline use requires a successful first load and service worker installation. Local storage may be cleared by browser or operating system, so use More > Save backup regularly. No account, cross-device sync, push notifications, or automatic dog training. Timer works while app is open. Use the iPhone Clock/Reminders app for background reminders.

The pickup date is a placeholder, December 1, 2026. Edit it in More. Training is paced by actual readiness, not the calendar. Do not mark milestones before the readiness criteria are met. The old version's name and arrival date can be imported automatically only if the browser shares the same storage origin; old lesson progress does not map directly to new lessons.
